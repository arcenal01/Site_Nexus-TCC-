# Política de segurança

## Reportando uma vulnerabilidade

Se encontrar uma falha de segurança neste projeto, **não abra uma issue pública**. Envie os detalhes de forma privada para o contato do autor indicado no perfil do repositório, incluindo:

- descrição do problema e do impacto;
- passos para reproduzir;
- versão ou commit analisado.

Você receberá uma confirmação de recebimento e, após a correção, o devido crédito (se desejar).

## Escopo

- O painel de demonstração é **público por design**: o acesso com a conta `demo` não é uma vulnerabilidade.
- São de interesse: contornar login, 2FA, limite de tentativas ou CSRF; XSS; upload de arquivos perigosos; acesso a `dados/`, `inc/` ou `ferramentas/`; vazamento de informações do servidor.

## Versões suportadas

Somente o ramo principal recebe correções.
