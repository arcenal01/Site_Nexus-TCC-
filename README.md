# 🎓 Nexus: TCC Completo (Demo)

Este repositório contém o **meu TCC completo**, com a parte visual e a **parte em PHP** já integradas.

> 🧪 **Este projeto é uma demo.** Ele serve para mostrar todas as funcionalidades que desenvolvi, mas não é um produto final de produção.

## 📖 Sobre o projeto

O Nexus é o resultado final do meu Trabalho de Conclusão de Curso no técnico em Desenvolvimento de Sistemas. Como usa **PHP**, o GitHub não consegue hospedá-lo online, então para ver o site funcionando você precisa rodá-lo na sua própria máquina.

## 💻 Como visualizar o projeto

O projeto está em **domínio público**, então você pode baixá-lo e usá-lo livremente. Para vê-lo funcionando, siga os passos:

### 1. Baixe o projeto

Clique em **Code → Download ZIP** no topo deste repositório e extraia a pasta no seu computador.

### 2. Instale um servidor local

Como o PHP precisa de um servidor para rodar, instale um destes programas (basta escolher um):

- [**XAMPP**](https://www.apachefriends.org/)
- [**Laragon**](https://laragon.org/)
- **WampServer**
- **MAMP**

### 3. Coloque o projeto na pasta do servidor

Copie a pasta do projeto para o diretório público do programa que você instalou:

- **XAMPP:** pasta `htdocs`
- **Laragon:** pasta `www`
- **WampServer:** pasta `www`
- **MAMP:** pasta `htdocs`

### 4. Inicie o servidor

Abra o programa e inicie os serviços **Apache** (e **MySQL**, caso o projeto utilize banco de dados).

### 5. Acesse no navegador

Abra o navegador e digite:

​```
http://localhost/NOME-DA-PASTA-DO-PROJETO
​```

Pronto! Agora é só explorar as funcionalidades da demo. 🚀
